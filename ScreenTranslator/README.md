# 화면 번역 (ScreenTranslator)

안드로이드에서 지금 보고 있는 화면(만화·웹툰·게임·앱)의 글자를 인식해 **한국어로 바꿔 그 자리에 덮어 그려 주는** 앱입니다.
기존 "Translate on Screen" 류 앱에서 불편했던 점을 고치는 것이 목표입니다.

| 불편했던 점 | 이 앱의 처리 |
|---|---|
| 화면을 움직일 때마다 번역 버튼을 다시 눌러야 함 | **자동 모드**: 화면을 계속 지켜보다가 스크롤이 멈추면 자동 번역. 이미 번역한 화면으로 돌아오면 저장된 결과를 바로 복원 |
| 번역 품질이 낮음 | LLM(Gemini / Claude)에게 화면 전체 문맥 + 직전 화면 기록을 함께 주어 말투·이름을 일관되게 번역 |
| 만화 효과음을 인식 못 함 | **만화 모드**: 스크린샷도 함께 보내 OCR이 놓친 효과음을 찾고 오인식을 보정. 효과음은 배경 없이 외곽선 글자로만 표시 |
| 번역이 배경을 가림 | 원문 주변 배경색을 샘플링해 **같은 색 상자 + 원문과 같은 글자색**으로 그 영역만 덮음. 버튼을 길게 누르면 원문이 보임 |

## 번역 엔진과 비용

엔진은 설정에서 바꿀 수 있고, 실패하면 자동으로 다음 엔진으로 넘어갑니다.

```
기본 엔진 (Gemini 또는 Claude)
  └─ 한도 초과(429)·오류 → Gemma (Gemini 키로 사용, 무료 한도가 큼)
       └─ 오류·오프라인 → ML Kit 온디바이스 번역 (품질 낮음, 무료)
```

* **Gemini (기본)** – [AI Studio](https://aistudio.google.com)에서 **결제를 연결하지 않은 프로젝트**의 키를 쓰면 무료입니다.
  2026-11 기준 무료 등급 한도(AI Studio 화면에서 확인한 값):
  * `gemini-3.5-flash-lite`: 분당 15회, **하루 500회** ← 기본값
  * `gemini-3.8-flash` 등 Flash 계열: 하루 20회 (만화 읽기에는 부족)
  * `gemma-4-31b` 계열: 하루 14,400회
  * 무료 등급은 보낸 내용이 구글 제품 개선에 쓰일 수 있습니다. 결제가 연결된 Tier 1 프로젝트면 토큰 단위로 과금됩니다.
* **Claude** – 유료. 기본값 `claude-haiku-5-5`(화면당 약 0.5~1원, 하루 200장 기준 월 4천 원 안팎). `claude-sonnet-5-5`, `claude-opus-5-5`로 바꿀 수 있습니다.
* **ML Kit** – 구글 번역 오프라인 모델. 품질은 낮지만 네트워크·키 없이 동작합니다.

플로팅 메뉴의 **엔진 비교**를 누르면 같은 화면을 Gemini와 Claude로 각각 번역해 나란히 보여 줍니다. 몇 장 비교해 보고 기본 엔진을 정하세요.

> Gemma 모델 ID(`gemma-4-31b-it`)는 실제 API에서 확인하지 못한 추정값입니다. "model not found"가 나오면 설정에서 ID를 고쳐 주세요.

## 사용 방법

1. 앱을 열고 API 키를 넣고, **번역할 언어**(일본어/중국어/영어 중 하나)를 고릅니다. 선택한 언어의 글자만 번역하고 나머지는 건드리지 않습니다.
2. **접근성 설정 열기** → 이 앱을 켭니다 (음량 버튼 단축키용. 화면 내용은 읽지 않습니다).
3. **번역 시작** → "다른 앱 위에 표시" 권한 → 화면 캡처 권한을 허용합니다. 플로팅 버튼은 없습니다.
4. 조작 방법 (번역이 켜져 있는 동안):
   * **음량 아래**: 지금 화면 번역
   * **음량 위**: 원문 보기 ↔ 번역 보기
   * 번역이 켜져 있는 동안 음량 버튼은 음량을 바꾸지 않습니다 (중지하면 원래대로)
   * **알림창**의 번역 / 원문 보기 / 중지 버튼, **빠른 설정 타일**(상단바를 내려 추가)도 같은 동작
   * 자동 모드가 켜져 있으면 스크롤이 멈출 때마다 알아서 번역하고, 같은 화면은 다시 요청하지 않습니다.
5. 상태·오류 메시지는 알림창과 앱 첫 화면의 "마지막 상태"에 표시됩니다.

세 손가락 제스처는 지원하지 않습니다: 다른 앱 위의 터치를 가로채려면 투명 창으로 터치를 막아야 해서 그 앱 조작이 불가능해지고, 접근성 서비스도 다른 앱의 터치를 볼 수 없습니다.

## 빌드

Android Studio에서 `ScreenTranslator` 폴더를 열고 실행하거나, 터미널에서:

```bash
cd ScreenTranslator
./gradlew :app:assembleDebug        # → app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest    # 단위 테스트
```

* minSdk 29 (Android 10), targetSdk 35. arm64 기기 전용 APK(약 90 MB, ML Kit 일·중·영 OCR 모델 포함).
* Maven Central이 429를 돌려줄 때를 대비해 `settings.gradle.kts`에 구글의 Maven Central 미러를 먼저 두었습니다.

## 알려진 제약

* **실기기에서 아직 검증하지 못했습니다.** 이 저장소의 코드는 컴파일·단위 테스트·lint까지만 통과한 상태입니다. 화면 캡처, 오버레이, OCR 품질은 실제 폰에서 확인이 필요합니다.
* 번역 상자는 기본 100% 불투명입니다. 상자마다 작은 창을 따로 띄우므로 상자 밖 터치는 그대로 통과하지만, Android 12 이상에서는 **번역 상자 위를 누르는 터치는 시스템이 차단**합니다(80% 이하로 낮추면 통과).
* 화면 회전은 지원하지 않습니다 (세로 기준). 회전하면 종료 후 다시 시작하세요.
* 효과음 위치는 모델이 이미지를 보고 추정한 값이라 정확하지 않을 수 있습니다.
* Android 14 이상은 보안 정책상 캡처 권한을 매번 다시 묻습니다.
* 이미 한국어인 영역은 번역하지 않습니다. 일본어/중국어 인식기는 한글을 한자·가나로 잘못 읽기 때문에, 한국어 인식기를 함께 돌려 한글로 읽힌 영역과 겹치는 블록을 버립니다.
* 배경 상자는 원문 **줄 단위** 영역에만 칠해지고, 글자 크기는 원문 글자 높이에서 시작해 들어갈 때까지 줄입니다.
* 세로쓰기(일본 만화) 블록은 OCR 결과를 그대로 상자로 쓰기 때문에, 긴 번역은 글자가 작아집니다. 글자 크기 배율로 조절하세요.
