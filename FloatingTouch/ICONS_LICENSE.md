# 아이콘 출처

플로팅 버튼 아이콘(`app/src/main/res/drawable/ic_page_down.xml`, `ic_page_up.xml`, `ic_auto_tap.xml`,
`ic_auto_scroll.xml`, `ic_stop.xml`, `ic_menu.xml`, `ic_settings.xml`)은
[Iconsax](https://iconsax.io) 아이콘의 Linear 스타일을 npm 패키지 `iconsax-react@0.0.8`
(MIT License, https://github.com/rendinjast/iconsax-react)에서 추출해 Android 벡터 드로어블로 변환한 것입니다.

| 파일 | Iconsax 이름 |
|---|---|
| ic_page_down | ArrowCircleDown |
| ic_page_up | ArrowCircleUp |
| ic_auto_tap | FingerCricle |
| ic_auto_scroll | Mouse |
| ic_stop | StopCircle |
| ic_menu | HambergerMenu |
| ic_settings | Setting2 |
